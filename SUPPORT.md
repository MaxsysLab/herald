# Getting Support

- **Questions and how-to:** open an issue and choose the Question template. Read
  [docs/QUICKSTART.md](docs/QUICKSTART.md) and [docs/CONFIGURATION.md](docs/CONFIGURATION.md)
  first; your answer may already be there.
- **A wrong answer from the officer:** open an issue with the Wrong Answer template and
  include the exact question and the exact reply.
- **Bugs:** open an issue with the Bug Report template.
- **Feature ideas:** open an issue with the Feature Request template. File the issue
  *before* a large pull request (see [CONTRIBUTING.md](CONTRIBUTING.md)).
- **Security vulnerabilities:** do **not** open a public issue. Follow
  [SECURITY.md](SECURITY.md).

We aim to give a first response within 3 business days. That is a target, not a
guarantee. Maintainers and contributors are volunteers; please be patient and kind.

Herald is open-source software offered as it is, without warranty (see
[LICENSE](LICENSE)). There is no paid support through this project.
